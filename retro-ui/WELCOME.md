## 🎮 Quick Start Guide

### Navigate Like It's 1985!

**Function Keys:**
- `F1` - Help & Documentation
- `F2` - Search for New Jobs
- `F3` - Run AI Enrichment
- `F4` - Apply to Jobs Menu
- `ESC` - Close Any Modal/Panel

### Or Use the Buttons:

1. **🔍 SEARCH JOBS**
   - Enter job title/keywords
   - Set max results (default: 25)
   - Choose location type (Remote/Hybrid/On-site)
   - Let it scrape for 2-5 minutes

2. **🤖 ENRICH JOBS**
   - AI analyzes all jobs
   - Identifies good fits
   - Generates application answers
   - Assigns fit scores (0-100%)

3. **⭐ VIEW GOOD FITS**
   - Browse your 35 matched jobs
   - See AI reasoning
   - Click for full details
   - Apply directly from job card

4. **✉️ APPLY TO JOBS**
   - Single job application
   - Batch apply to good fits
   - Track application history

5. **👤 PROFILE**
   - View active profile details
   - Check application stats
   - See success rate

## 🛠️ Useful Commands

### Check System Status
```bash
cd retro-ui
./status.sh
```

### Restart Backend
```bash
cd retro-ui
./start.sh
```

### View Logs
```bash
# Backend logs (if not backgrounded)
cd retro-ui
node server.js

# Action server logs
ls -la ../output/
```

### Query Database Directly
```bash
# Via UI: Use the "query_database" action
# Or terminal:
sqlite3 ../src/linkedin_jobs.sqlite "SELECT * FROM job_postings LIMIT 5;"
```
